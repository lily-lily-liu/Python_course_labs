# Python Vibe Coding Lab1 - 销售报表生成工具

## 项目简介

本工具读取带脏数据的原始销售 Excel，自动完成数据清洗与多维度统计，并输出规范报表。

## 环境依赖

- Python 版本：Python 3.10 或更高版本
- 在项目根目录安装依赖：

```bash
pip install -r requirements.txt
```

## 运行说明

在项目根目录运行以下命令：

```bash
python -m sales_report.cli --input testdata/sales_raw.xlsx --output report.xlsx
```

- `--input`：原始 `.xlsx` 销售数据文件路径。Excel 首个工作表须包含 `日期`、`销售员`、`产品`、`数量`、`单价`、`地区` 六个字段。
- `--output`：生成的 `.xlsx` 报表保存路径。
- 如果使用 `tools/make_sample.py` 生成的测试文件，请将输入路径替换为 `testdata/sales_raw_sample.xlsx`。

## 测试说明

在项目根目录运行全量 pytest 测试：

```bash
python -m pytest -v
```

测试覆盖合法数据及销售员汇总、关键字段空值行剔除、数量小于等于零的记录剔除、空白工作簿缺少必需字段，以及清洗后无有效数据等场景。测试文件在 pytest 的临时目录中创建，不会修改项目里的原始样例数据。

## 输出说明

生成的 `report.xlsx` 包含以下四个工作表：

| 工作表 | 用途 |
| --- | --- |
| 明细清洗后 | 清洗、去重后的销售明细，并包含按数量乘以单价计算的销售额 |
| 按销售员 | 按销售员汇总销售额 |
| 按地区 | 按地区汇总销售额 |
| 总览 | 按月份汇总的销售额 |

## 异常场景说明

- 输入文件不存在：打印 `错误：指定的输入文件不存在，请检查路径`。
- 输入文件损坏或不是合法 Excel：打印 `错误：输入文件不是合法的Excel文件`。
- 清洗后没有有效记录：生成包含四个工作表和表头的空报表模板，并打印 `提示：原始数据清洗后没有剩余有效记录，已生成空报表模板`。
- Excel 缺少必需字段、数据格式无效或报表写入失败等其他异常：打印 `运行出错：` 和对应异常描述。
- 参数缺失时，命令行会提示必填参数并以错误状态退出。

报表程序以只读方式加载输入文件，不会修改原始输入文件；如果输入和输出路径指向同一文件，程序会拒绝覆盖。
